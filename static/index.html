2. 애플리케이션 이름: 아무거나 입력 (예: "마케케")

4. 환경 추가: "WEB 설정" 선택

            
5. 웹 서비스 URL: http://localhost 입력

            
6. "등록하기" 클릭

            
7. 발급된 Client ID와 Client Secret을 위 입력란에 붙여넣기

          


          
2단계. 검색광고 API (키워드 검색량)

3. "네이버 검색광고 API 서비스 신청" 클릭

            
4. 발급된 API License, Secret Key, Customer ID를 위 입력란에 붙여넣기
